# qtcloud-meta：给大模型补上 System 2

一个人脑子里有两套思考。System 1 快、省力、凭直觉，看见半张脸就能认出是谁；System 2 慢、费力、讲道理，算 17 × 24 得靠它。两套都得有——只靠 System 1，快是快，但会在要紧的地方想当然。

大模型很像 System 1。问它什么都能立刻答，语气笃定，语言流畅。但它给的是「最像对的」答案，不是「推出来的」答案。所以它能写出一封像模像样的合规意见，却引错一条条款；能把一段流程讲得头头是道，却漏掉一个前提。

qtcloud-meta 补的是 System 2。

它把领域知识写成本体——有哪些事物、彼此什么关系、必须满足什么约束——再按确定的规则做推理。它的结论带得动证据链：每一步都能追到依据；结论不成立时，会指出是哪条规则没满足。它不「编」，因为它不是在猜下一个词，是在推下一步。

能做的：

- **形式化推理。** 以 API 形式提供推理，像调用大模型一样调用它；
- **状态校验。** 给一组前置条件，判断某个动作此刻能不能做；不能做时，指出卡在哪条规则；
- **跨领域组合。** 不同领域的知识各自成篇，靠一层结构对应的映射拼在一起；拼得对不对，由测试证明；
- **归档。** 把加载过的本体打包成一个自包含的文件，读取时先验指纹，被改过就拒收。

现状：正在从可用的推理内核往服务走。第一步做范畴计算，第二步把概念之间的关系结构算进来，再做登录与支付；到 1.0，以 API 对外提供形式化推理，按计算量计费。
