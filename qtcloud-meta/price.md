# 定价

qtcloud-meta 提供的是一种确定性的计算服务：客户把领域规则交给它，它按形式化推理算出对业务有用的结果，再配合大模型的能力，一起交付给客户。它不像大模型那样按 token 猜下一个词，而是按规则推出下一步，所以结果可以和算力一样按用量结算。

价格分两块。

**一、存核心信息。** 客户的核心资产是那套领域本体：有哪些概念、彼此什么关系、必须满足什么约束。这套东西写清楚之后要长期保存、随时取用，占的是存储。这一块按存放的本体与范畴计费。

**二、算。** 每一次形式化推理都要消耗计算。这一块按推理的计算量计费，对齐大模型 API 的按量付费方式：用多少算多少，不用不计。

两块分开，是因为它们对应两种不同的成本：存是一次投入、长期占用；算是一次次发生、随调用增长。混在一起报价，客户看不清钱花在哪，我们也不清楚该按什么扩容。

支付能力随 1.0 上线，以上是届时采用的计费口径。
